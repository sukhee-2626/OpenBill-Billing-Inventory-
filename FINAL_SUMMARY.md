## 🎨 UI/UX Design System

### Color Gradients
- **Primary**: Blue (#667eea) → Purple (#764ba2)
- **Success**: Green (#10b981) → Emerald (#059669)
- **Warning**: Orange (#f59e0b) → Amber (#d97706)
- **Danger**: Red (#ef4444) → Crimson (#dc2626)

### Components
- **Glass cards**: `rgba(255,255,255,0.8) + backdrop-blur(20px)`
- **Premium shadows**: `0 10px 40px rgba(0,0,0,0.1)`
- **Hover lift**: `transform: translateY(-4px)`
- **Button shine**: Sliding gradient overlay

### Animations
- **Gradient shift**: 15s infinite color flow
- **Badge pulse**: 2s opacity + scale pulse
- **Shimmer loading**: 2s sliding gradient
- **Glow pulse**: 2s shadow intensity change

## 💎 Premium Features Showcase

### UPI Payment Flow
1. Customer scans QR code with any UPI app
2. Pays ₹X amount
3. Gets 12-digit UPI transaction ID
4. Merchant enters ID in modal
5. System verifies (simulated for now)
6. Payment recorded automatically
7. Invoice status updated to "paid"
8. Stock deducted
9. Success animation displayed

### WhatsApp Sharing
1. Click "WhatsApp" button on invoice
2. Pre-formatted message opens with:
   - Customer name
   - Invoice number & date
   - Amount & status
   - Business contact details
3. Send directly from WhatsApp

### Image Upload
1. Click "Upload Logo/Signature/Stamp"
2. Select image (PNG/JPG/SVG, max 2MB)
3. Preview shows instantly
4. Save in settings
5. Auto-appears on all invoices
6. Positioned correctly (logo header, signature bottom-right, stamp bottom-left)
